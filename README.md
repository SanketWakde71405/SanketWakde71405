# 💫 About Me:
My name is Sanket Wakde, and I am a final-year B.Tech student in Information Technology at Shri Guru Gobind Singhji Institute of Engineering and Technology, Nanded. <br>I am passionate about mobile and web application development, with hands-on experience in React Native, React.js, JavaScript, and Android development.<br>I recently completed a React Native Developer Internship at A2Developers, where I worked on the Vidyamint School Management App, contributing to UI development and REST API integration. <br>I have also built several projects including a Weather App (PWA) using React, a Mini Inventory Management System using React and SQLite, and an Android-based component management app for my college robotics club.<br>I enjoy building practical applications that solve real problems and continuously improving my skills in modern web and mobile technologies.<br>
